# Cafe Management System

### Project Overview
The **Cafe Management System** is a robust and user-friendly Java-based application developed as a **semester project** for the **Object-Oriented Programming (OOP)** course. The system is designed to streamline cafe operations, such as managing orders, calculating bills, and maintaining inventory.  

---

### Features
- **Order Management**: Efficiently place, modify, and delete customer orders.
- **Menu Management**: Display available items with prices and categories.
- **Billing System**: Automatically calculate total amounts and generate bills.
- **Inventory Tracking**: Manage stock levels and alert for low inventory.
- **Admin Panel**: Add, update, or remove menu items and view sales reports.
- **User-Friendly Interface**: Simple and intuitive console-based navigation.
- **Object-Oriented Design**: Implements OOP principles like inheritance, encapsulation, abstraction, and polymorphism.

---

### Technologies Used
- **Programming Language**: Java
- **IDE**: VS code
- **File Handling**: To store menu items, orders, and sales data.
- **Data Structures**: Utilizes collections like `ArrayList` and `HashMap` for efficient data management.

---

### How It Works
1. **Admin Mode**:
   - Login to the admin panel.
   - Manage the menu: add, update, or remove items.
   - View inventory and sales reports.
2. **Customer Mode**:
   - Browse the menu.
   - Place an order by selecting items and quantities.
   - Review the order summary and confirm the purchase.
3. **Billing**:
   - Automatically calculates the bill, including applicable taxes.
   - Provides an option to print or save the bill.
